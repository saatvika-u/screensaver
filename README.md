# Web-Based Kiosk Screensaver

A web-based kiosk screensaver featuring a live digital clock, background music, and interactive controls.

The screensaver plays The Imperial Suite and allows users to switch between 10 Star Wars themed backgrounds using the number keys 0-9. Designed for full screen display.
